## 셔뱅(shebang)의 의미

- **셔뱅은 스크립트 파일의 맨 앞에 `#!`로 시작하는 줄을 두어, 해당 파일을 실행할 프로그램(보통 인터프리터)을 지정하는 방식이다.**
- Python 전용 문법이 아니며, Bash·Python·Perl 등 여러 언어의 스크립트에서 사용한다.

```
#!interpreter [optional-arg]
```

- `#!`는 파일의 첫 두 문자여야 한다. 앞에 빈 줄이나 공백을 두지 않는다.
- 인터프리터 경로에 실제 실행 가능한 프로그램이 있어야 한다. 
선택적 인자의 처리 방식은 운영체제별로 차이가 있다.
- 참고: [Linux execve(2) — Interpreter scripts](https://man7.org/linux/man-pages/man2/execve.2.html), [GNU Bash — Shell Scripts](https://www.gnu.org/software/bash/manual/html_node/Shell-Scripts.html)
    
    ```c
    #include <unistd.h>
    
           int execve(const char *path, char *const _Nullable argv[],
                      char *const _Nullable envp[]);
    ```
    
    - execve: path 로 지정된 프로그램을 실행한다.
        
        > path must be either a binary executable, or a script starting with a line of the form:  `#!interpreter [optional-arg]`
        > 

## 주석 아니었냐?

예시 코드

```python
#!/Users/seungwoo/Desktop/2026-1/whisper_batch/.venv/bin/python3
import sys
from yt_dlp import main
if __name__ == '__main__':
    sys.argv[0] = sys.argv[0].removesuffix('.exe')
    sys.exit(main())
```

- **Python이 소스 코드를 읽을 때:** 첫 줄은 `#`로 시작하는 주석이므로 Python 코드로 실행하지 않는다.
- **Linux·macOS가 파일 자체의 실행을 처리할 때:** 파일 시작의 `#!`를 인식하여 지정된 프로그램을 실행하고, 스크립트 경로를 인자로 전달한다.
- 위 예시는 `whisper_batch/.venv/bin/python3`라는 **특정 가상환경의 Python**으로 이 스크립트를 실행하라는 뜻이다.
- 따라서 동일한 줄이 Python에는 주석이고, 운영체제에는 실행할 프로그램을 지정하는 정보가 된다.

## `./hello.py`가 가능하다고?

- `./hello.py`: “현재 디렉터리에 있는 `hello.py` 파일을 실행해라”

### 1. 스크립트 작성

`hello.py` 파일의 첫 줄에 셔뱅을 넣는다.

```python
#!/usr/bin/env python3
print("Hello!")
```

`/usr/bin/env python3`의 경우 

- 운영체제가 먼저 `/usr/bin/env`를 실행한다.
- `env`가 현재 환경의 `PATH`를 뒤져서 `python3`를 찾고 실행한다.
- 특정 가상환경의 Python 경로를 직접 적는 방식과 달리, 실행 당시의 `PATH`에 따라 사용할 Python이 달라질 수 있다.

### 2. 실행 권한 부여

```bash
chmod +x hello.py
```

### 3. 파일 직접 실행

```bash
./hello.py
```

운영체제가 셔뱅에 지정된 프로그램을 실행하고 스크립트 경로를 넘기면, 최종적으로 Python이 파일을 읽어 `Hello!`를 출력한다.

### 직접 실행과 Python에 파일을 넘기는 방식의 차이

| 실행 명령 | 사용할 Python 선택 | 스크립트에 필요한 조건 |
| --- | --- | --- |
| `./hello.py` | 셔뱅에 지정된 프로그램을 통해 선택 | 이 방식으로 Python을 지정하려면 셔뱅과 실행 권한이 필요 |
| `python3 hello.py` | 명령으로 호출한 `python3` 사용 | 읽을 수 있는 파일이면 되며, 셔뱅과 실행 권한은 불필요 |
